## 🧱 Button Components Overview

### `<PrimaryButton />`
Use for main actions like "Submit", "Continue", or any CTA.

### `<IconButton />`
Use for compact icon-based buttons in Flashcard UIs or toolbars.

### `<TextButton />`
Use for inline text-style actions like "Show Example", "Cancel", or toggles.

Each supports:
- `onClick`, `disabled`, `className`
- Optional `icon` or `children`
- Mobile-friendly spacing + accessibility
